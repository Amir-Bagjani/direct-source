# بازارگاه تأمین مستقیم

بازارگاه مدیریت‌شدهٔ B2B برای اتصال مستقیم تولیدکنندگان کیف و کفش به خرده‌فروشان سراسر ایران. تولیدکننده فروشنده و مالک موجودی باقی می‌ماند و پلتفرم در ازای شکل‌گیری معامله کارمزد می‌گیرد (نرخ اولیه ۴٪ با سهم برابر دو طرف).

- **وضعیت**: کشف کلان محصول تکمیل شده است — ۲۲ از ۲۲ دروازه بسته‌اند؛ نقشهٔ جزئیات development و PRDها هنوز تیکت باز دارد.
- **گام بعدی**: بستن [نقشهٔ تصمیم‌گیری محصول](.scratch/mvp-plan/map.md) و PRDها، سپس بازبینی [برنامهٔ فنی بک‌اند](docs/technical/backend/README.md)، پذیرش ADRها، مدل دامنه، ERD و قراردادهای API.
- **زبان**: همهٔ اسناد فارسی‌اند. واژه‌های مشترک دامنه در [`CONTEXT.md`](CONTEXT.md) تثبیت شده‌اند و باید در کل پروژه رعایت شوند.

## ساختار پروژه

```text
.
├── apps/
│   ├── frontend/          # اپ Next.js (آماده‌سازی — هنوز کدی نیست)
│   └── backend/           # اپ Django (آماده‌سازی — هنوز کدی نیست)
├── docs/
│   ├── product/
│   │   ├── vision/        # چشم‌انداز، جمع‌بندی کشف، بازار و جذب
│   │   └── requirements/  # ۱۸ سند نیازمندی تأییدشده
│   ├── technical/
│   │   ├── architecture/  # ADRها و فرایند تصمیم‌گیری
│   │   ├── backend/       # طرح معماری و برنامهٔ مرحله‌ای توسعه
│   │   ├── api/           # (جای قراردادهای API — خالی)
│   │   └── database/      # (جای ERD و مدل داده — خالی)
│   └── diagrams/          # ۲۰ نمودار HTML + فهرست (index.html) و README
├── assets/
│   └── pdf/               # بایگانی خروجی PDF اسناد (تولیدشده)
├── scripts/               # اسکریپت‌های تولید خروجی (فعلاً خالی)
├── CONTEXT.md             # واژه‌نامهٔ دامنه + دستورالعمل دستیارها
├── opencode.json          # پیکربندی ابزار opencode
├── README.md
└── .gitignore
```

## اسناد

فهرست کامل با توضیح یک‌خطی هر سند: [`docs/README.md`](docs/README.md)

ورودی‌های پیشنهادی:

1. [جمع‌بندی کشف](docs/product/vision/discovery-summary.md) — تصویر کلان محصول در چند بخش
2. [سند زندهٔ محصول](docs/product/vision/product.md) — تصمیم‌های قطعی و گزارش جلسات کشف
3. [واژه‌نامهٔ دامنه](CONTEXT.md) — زبان مشترک پروژه

## توسعه

پروژه فعلاً فقط مستندات است. `apps/frontend` و `apps/backend` پس از بستن شکاف‌های محصول و نهایی‌شدن طراحی دامنه و API، به ترتیب با Next.js و Django پر می‌شوند.

- **نمودارها**: `docs/diagrams/index.html` را در مرورگر باز کنید؛ همهٔ نمودارها HTML مستقل‌اند و بدون سرور یا ابزار اجرا می‌شوند.
- **PDFها**: بایگانی `assets/pdf/` خروجی تولیدشدهٔ اسناد است؛ چیدمان پوشه‌های آن مربوط به ساختار پیش از بازآرایی است و پس از جابه‌جایی بازتولید نشده است.

## دسته‌بندی فایل‌ها

| گروه | مسیر | توضیح |
|---|---|---|
| اسناد محصول و چشم‌انداز | `docs/product/vision/` | سند زندهٔ محصول، جمع‌بندی و نقشهٔ راه کشف، محدودهٔ بازار، جذب |
| نیازمندی‌های MVP | `docs/product/requirements/` | ۱۸ سند جریان و قواعد تأییدشده |
| تصمیم‌های معماری | `docs/technical/architecture/adr/` | دو ADR |
| نمودارها | `docs/diagrams/` | ۲۰ نمودار HTML خودکفا + فهرست |
| خروجی تولیدشده | `assets/pdf/` | ۲۲ فایل PDF + MANIFEST (بایگانی) |
| پیکربندی ابزار | `CONTEXT.md`، `opencode.json` | واژه‌نامهٔ دامنه و پیکربندی opencode |

## موارد باز یا مبهم

- **`CONTEXT.md` در ریشه می‌ماند** زیرا opencode آن را به‌عنوان دستورالعمل پروژه بارگذاری می‌کند؛ محتوایش واژه‌نامهٔ دامنه است و در فهرست اسناد هم ثبت شده است.
- **`assets/pdf/`** خروجی تولیدشدهٔ اسناد با چیدمان قدیمی است؛ اسکریپت تولید PDF و نمودارها در مخزن موجود نیست (تنها `__pycache__` باقی مانده بود که پاک شد). در صورت بازتولید، ساختار پوشه‌ها باید به چیدمان جدید به‌روز شود.
- **`docs/technical/api/` و `docs/technical/database/`** خالی‌اند و پس از طراحی دامنه پر می‌شوند.
- مخزن git نیست؛ در صورت نیاز `git init` اجرا کنید (`.gitignore` آماده است).
