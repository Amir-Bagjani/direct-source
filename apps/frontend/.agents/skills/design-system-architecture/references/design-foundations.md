# Foundations

The official shadcn/ui components and configured Base UI / Nova / neutral preset own
appearance. PRDs own behavior, content and feature scope. Use built-in variants and
composition; do not restore the previous bespoke palette, fractional radii or CSS controls.
Both locales and both explicit themes share these components. Foundation components
include Button, Input, Dialog, ToggleGroup and Spinner; Modal adapts Dialog to URL history.
