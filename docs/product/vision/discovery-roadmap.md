# نقشهٔ راه کشف و طراحی MVP

این نقشه، مصاحبهٔ طراحی محصول را به مجموعه‌ای محدود از تصمیم‌های اصلی تبدیل می‌کند تا گفت‌وگو هدف و نقطهٔ پایان روشن داشته باشد.

## وضعیت

- کل دروازه‌های تصمیم اصلی: ۲۲
- حل‌شده: ۲۲
- باقی‌مانده: ۰
- سقف پرسش‌های شرطی برای رفع تناقض‌ها و لبه‌های حیاتی: ۰
- حداکثر پاسخ‌های باقی‌مانده تا پایان کشف: ۰

## روش پیشروی

- در هر نوبت فقط یک سؤال اصلی مطرح می‌شود.
- همراه هر سؤال، پاسخ پیشنهادی و دلیل آن ارائه می‌شود.
- پس از تأیید، تصمیم بلافاصله در اسناد محصول و واژه‌نامه ثبت می‌شود.
- سؤال‌های جزئی که مانع تعریف یا ساخت MVP نیستند به فهرست «بعد از MVP» منتقل می‌شوند.
- پس از پایان هر مرحله، یک جمع‌بندی کوتاه و کنترل تناقض انجام می‌شود.

## مرحلهٔ ۱ — مدل کسب‌وکار و مرز بازارگاه

پیشرفت: ۴ از ۴ — تکمیل‌شده

- [x] نقش پلتفرم در معامله و مالکیت کالا
- [x] زمان رزرو و قطعی‌شدن کارمزد
- [x] تقسیم کارمزد میان طرفین
- [x] ساختار نرخ کارمزد و مقدار اولیه

خروجی مرحله: مدل درآمدی و مرز مسئولیت اقتصادی پلتفرم.

## مرحلهٔ ۲ — بازیگران، عضویت و اعتماد

پیشرفت: ۳ از ۳ — تکمیل‌شده

- [x] شرایط پذیرش تولیدکننده و خرده‌فروش
- [x] مدارک، احراز هویت و فرایند تأیید
- [x] رابطهٔ کسب‌وکار با کاربران و نقش‌های داخلی هر حساب

خروجی مرحله: تعریف دقیق بازیگران و قواعد ورود به بازارگاه.

## مرحلهٔ ۳ — کاتالوگ و قواعد فروش عمده

پیشرفت: ۴ از ۴ — تکمیل‌شده

- [x] ساختار محصول، مدل، رنگ، سایز و سایر تنوع‌ها
- [x] حداقل سفارش، بسته‌بندی و امکان ترکیب تنوع‌ها
- [x] قیمت عمده، قیمت پلکانی و سطح دسترسی به قیمت
- [x] موجودی آماده، تولید سفارشی و زمان آماده‌سازی

خروجی مرحله: مدل عرضه‌ای که هم کیف و کفش را پوشش دهد و هم توسعه‌پذیر باشد.

## مرحلهٔ ۴ — سفارش، پرداخت و تسویه

پیشرفت: ۴ از ۴ — تکمیل‌شده

- [x] مرز سبد خرید و سفارش برای چند تولیدکننده
- [x] تأیید سفارش، انقضا و تغییرات پیش از پرداخت
- [x] روش‌های پرداخت و جایگاه خرید اعتباری یا مدت‌دار
- [x] زمان و قواعد تسویه، بازپرداخت و تعدیل کارمزد

خروجی مرحله: گردش کامل پول و وضعیت‌های سفارش.

## مرحلهٔ ۵ — ارسال و خدمات پس از معامله

پیشرفت: ۴ از ۴ — تکمیل‌شده

- [x] مسئول ارسال، انتخاب روش حمل و پرداخت هزینهٔ آن
- [x] اثبات ارسال و تحویل
- [x] مغایرت، عیب، کسری، لغو و مرجوعی
- [x] رسیدگی به اختلاف و حدود دخالت پلتفرم

خروجی مرحله: قواعد عملیاتی معامله از آماده‌سازی تا بسته‌شدن پرونده.

## مرحلهٔ ۶ — محدودهٔ MVP، عرضه به بازار و سنجش موفقیت

پیشرفت: ۳ از ۳ — تکمیل‌شده

- [x] بازار جغرافیایی و زیرگروه دقیق شروع
- [x] عملیات دستی، پنل مدیریت و قابلیت‌های ضروری MVP
- [x] روش جذب دو سمت بازار و معیار موفقیت MVP

خروجی مرحله: محدودهٔ نهایی MVP، برنامهٔ آزمایش بازار و معیار عبور به توسعه.

## نقطهٔ پایان کشف

این نقطه محقق شده است: هر ۲۲ دروازهٔ اصلی تعیین تکلیف شده، تناقض مسدودکننده‌ای باقی نمانده و سناریوی کامل MVP از ثبت‌نام تولیدکننده تا تسویهٔ داخلی و امتیازدهی تعریف شده است. خروجی بعدی، مدل دامنه و مدل دیتابیس خواهد بود.
